📁 **Proje kodu ve kurulum:** [admin-dashboard/README.md](admin-dashboard/README.md)

## GitHub'a yükleme

Depo yerelde hazır. GitHub’a atmak için:

1. **GitHub’da yeni boş repo oluştur:**  
   https://github.com/new  
   (README, .gitignore ekleme; boş repo oluştur.)

2. **Remote ekleyip gönder:**
   ```bash
   git remote add origin https://github.com/KULLANICI_ADINIZ/REPO_ADI.git
   git branch -M main
   git push -u origin main
   ```
   `KULLANICI_ADINIZ` ve `REPO_ADI` yerine kendi GitHub kullanıcı adınızı ve repo adınızı yazın.

SSH kullanıyorsanız:
   ```bash
   git remote add origin git@github.com:KULLANICI_ADINIZ/REPO_ADI.git
   git push -u origin main
   ```

Not: Bu projede varsayılan dal `master`. `main` kullanmak isterseniz `git branch -M main` ile dal adını değiştirebilirsiniz; yoksa `git push -u origin master` yazın.
